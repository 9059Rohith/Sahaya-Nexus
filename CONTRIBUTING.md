# Contributing

Keep the unified request lifecycle and server-side authorization intact. Do not add seeded activity, fabricated verification badges or synthetic impact totals to production paths. Add an Alembic migration for schema changes. Keep domain-specific fields in validated schemas and make priority/matching reasons visible to people.

Run backend pytest and Ruff, then frontend lint, typecheck and build. Add integration tests for new privileged transitions and object access. Verify small screens and keyboard operation when changing UI. Translate new interface strings into all four language dictionaries or document the gap in the change.
