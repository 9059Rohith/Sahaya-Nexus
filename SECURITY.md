# Security

Passwords use Argon2. FastAPI signs 12-hour HS256 tokens with a unique session ID; server-side sign-out revokes that ID, and expired revocations are pruned. The Next.js proxy stores the token in an HTTP-only, same-site cookie and does not return it to browser JavaScript. The proxy checks Origin or same-origin fetch metadata for mutations and caps request bodies. SQLAlchemy parameterizes database operations. Public and authenticated queries are scoped server-side, and request/evidence reads enforce owner, staff or assigned-responder access. User input cannot assign a role, verify a request or select an ineligible responder.

The lifecycle rejects skipped stages. Each transition, verification, priority override, policy change and matching decision has an actor and reason in audit data. The Docker stack uses atomic Redis counters shared across API workers for mutation rate limits; a local Python process without Redis uses an in-process limit. If configured Redis becomes unavailable, mutation requests fail with a retryable 503. Uploaded evidence is capped at 5 MB and restricted to JPEG or PNG signatures; images are decoded and re-encoded to strip metadata, stored under UUID filenames, and downloaded as attachments only after authorization. File names do not choose storage paths. FastAPI sets content-type, framing, referrer and restrictive CSP response headers. The browser proxy does not cache private API responses.

The local LLM can only propose bounded category and quantity fields. Pydantic and deterministic business rules validate them; the model cannot perform privileged actions. Voice transcripts require human review and editing before submission. Blood coordination does not provide clinical advice.

The platform policy supports an optional, audited retention period for closed request content. It is off until an administrator selects a period. The maintenance worker redacts eligible request text and private files in bounded batches; open abuse cases are excluded.

This is a security baseline, not a completed public security assessment. There is no MFA. New PDF uploads are refused because they cannot be content scanned; existing private PDFs remain downloadable by authorized users. Before Internet exposure, provide HTTPS through a trusted reverse proxy, monitored backups and restore testing, admin recovery, independent authorization review and operational incident response. Keep `SECRET_KEY` and `POSTGRES_PASSWORD` outside source control. The first admin is created interactively through the CLI.
